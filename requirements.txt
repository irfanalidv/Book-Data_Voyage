# Data Voyage — production requirements
# Pinned to versions current as of September 2026.
# Python: 3.11 or 3.12 recommended. Tested against 3.11.
#
# Pinning strategy:
#   - Compatible-release operator (~=) on key libraries: locks the minor
#     version but allows patch updates (bug fixes, security).
#   - Strict equality (==) on libraries that have broken across patch
#     versions in the past (pydantic, fastapi).
#   - Upper bounds (<X) where a known-breaking major release exists.
#
# This file is the abstract dependency layer (compatible-release pins).
# Readers and CI install from requirements-lock.txt (exact pins).
# Regenerate: make lock  (requires uv)
#
# If you find a library used by chapter code that is not pinned here, that is a bug
# — open an issue.
